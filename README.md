# Розробка системи автономної візуальної навігації для БПЛА

Магістерська робота. Автономний проліт квадрокоптера DJI Robomaster TT
(Tello) крізь обруч за даними монокулярної камери.

**Виконав:** Фелонюк І. В., гр. КНСШ-13
**Керівник:** Пшеничний О. Ю.

## Мета

Підвищення ефективності та стабільності автономної навігації БПЛА в
GPS-дефіцитних середовищах шляхом порівняльного дослідження методів
візуальної детекції та стратегій керування.

## Будова репозиторію

Дрон з'єднаний з ноутбуком по Wi-Fi: ноутбук приймає відеопотік,
обробляє кадри й надсилає команди керування. Уся обробка — на ноутбуку.

### `src/` — бібліотека

| Каталог | Що містить |
|---|---|
| `src/detection/` | детектори обруча за спільним інтерфейсом, вибір треку |
| `src/pose/` | оцінка 3D-пози обруча: розклад коніки та `solvePnP` |
| `src/control/` | стратегії керування IBVS, PBVS, гібрид; ПІД; компенсація затримки |
| `src/drone/` | з'єднання з Tello: відеопотік, телеметрія, канали керування |
| `src/sim/` | модель руху дрона, камери та деградацій зображення |
| `src/synth/` | генератор синтетичних навчальних даних |
| `src/viz/` | вікно живого перегляду та накладання діагностики на кадр |

### `experiments/` — запускні скрипти

| Скрипт | Призначення |
|---|---|
| `tello_fly.py` | політ: замкнений контур на дроні |
| `tello_check.py` | перевірка з'єднання, каналів керування і телеметрії |
| `tello_measure_fx.py` | вимір фокусної відстані камери без зльоту |
| `tello_calibrate_scale.py` | узгодження оцінки дистанції з реальною |
| `latency_on_drone.py` | вимір затримки відеотракту |
| `closed_loop_sim.py` | замкнений контур у симуляторі, без дрона |
| `live_sim.py` | інтерактивне вікно симулятора |
| `calibrate_camera.py`, `show_calib_pattern.py` | калібрування камери за шахівницею |
| `generate_synthetic_dataset.py` | генерація синтетичного набору |
| `train_detectors.py` | навчання детекторів |
| `benchmark_detectors.py`, `eval_labeled.py`, `cross_dataset_eval.py` | оцінка детекторів |
| `compare_controllers.py`, `collect_metrics.py` | зведення порівнянь і метрик |

### Інші каталоги

| Каталог | Що містить |
|---|---|
| `calibration/` | параметри камер у JSON і шаблон шахівниці |
| `datasets/`, `models/`, `runs/` | дані, ваги й результати навчання — у git не входять |

## Встановлення

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

**Важливо про CUDA.** Свіжий `torch` з PyPI зібраний під CUDA 13.0.
На драйверах, що підтримують лише CUDA ≤ 12.2 (напр. 535), він мовчки
працює на CPU без повідомлення про помилку. Потрібна збірка cu121:

```bash
.venv/bin/pip install -r requirements-cuda.txt \
    --index-url https://download.pytorch.org/whl/cu121
.venv/bin/python -c "import torch; print(torch.cuda.is_available())"
```
